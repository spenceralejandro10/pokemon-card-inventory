¿Cómo realizar una compra?

Explora el catálogo, selecciona los productos que te interesan y envía una propuesta por WhatsApp. El analista confirma disponibilidad, negocia contigo y, si llegan a un acuerdo, genera un código de venta asociado exactamente a esos productos.

¿Qué es el código de venta?

Es la autorización que conecta tu negociación con el pedido. Sin un código válido no se habilitan datos de entrega, Top Loaders, cotización ni generación del PDF.

¿Qué pagas en esta etapa?

Después de validar el código pagas únicamente el transporte, el manejo logístico y los Top Loaders opcionales. La negociación comercial se gestiona por separado con el analista.

Sobre CardNest

CardNest organiza cartas, coleccionables, accesorios, producto sellado y electrónica en un solo catálogo. Cada compra se acompaña por WhatsApp y utiliza un código de venta para mantener trazabilidad entre la negociación, el envío y el comprobante.

Después de enviar el comprobante

El analista identifica la operación mediante el código, verifica el pago del envío y, una vez confirmado, continúa internamente con el proceso de alistamiento y despacho. Los envíos directos de CardNest se gestionan con Coordinadora y quedan sujetos a las condiciones del servicio logístico aplicable.
