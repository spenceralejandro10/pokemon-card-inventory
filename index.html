Ventajas de esta forma de envío

Comprador: no adelanta el valor de las cartas; primero cubre el envío y las cartas se pagan contra entrega.

Vendedor: el transporte queda cubierto antes de despachar.

¿Cómo funciona el proceso?

1. Acuerdas las cartas y el precio. 2. Registras los datos de entrega. 3. Generamos una referencia válida por 4 horas. 4. Pagas el envío. 5. Envías comprobante + referencia por WhatsApp. 6. Gestionamos el despacho.

Condiciones y tiempos de despacho

El envío se paga antes del despacho. Pedidos confirmados antes de las 12:00 m. se preparan para salir el mismo día; después se programan para el siguiente día hábil, salvo que la operación permita despacharlos antes.

Despacho y entrega

Pedidos confirmados antes de las 12:00 m.: los preparamos para despacho el mismo día.

Después de las 12:00 m.: se programan para el siguiente día hábil; cuando la operación lo permita, intentaremos despacharlos ese mismo día.

El tiempo de transporte empieza una vez Coordinadora recibe el paquete. Coordinadora informa los tiempos en días hábiles según origen y destino y advierte que pueden variar por vías, clima u otras condiciones logísticas.

Al continuar confirmas que entiendes que el envío se paga obligatoriamente antes del despacho. El valor de las cartas se recauda contra entrega. El 1% mostrado corresponde al manejo que Coordinadora publica sobre el valor declarado.
